## What's Inside

Crafted Gamz is organized around three environments, each designed for a different style of use.

<CardGroup cols={3}>
  <Card title="Website Mode" icon="globe" href="/modes/website">
    The classic game-site experience with 100+ games, apps, AI chat, media, and proxy search.
  </Card>
  <Card title="Desktop Mode" icon="desktop" href="/modes/desktop">
    A macOS-style browser desktop with windows, a dock, an app store, and an AI assistant.
  </Card>
  <Card title="Browser Mode" icon="browser" href="/modes/browser">
    A full proxy browser with tabs, bookmarks, an address bar, and server switching.

<Steps>
  <Step title="Open Crafted Gamz">
    Navigate to the platform in any modern browser — no installation required. It works on Chromebooks, Windows, macOS, and Linux.
  </Step>
  <Step title="Choose a mode">
    Pick Website for immediate access to games and tools, Desktop for a full OS-like environment, or Browser for a dedicated proxy browsing experience.
  </Step>
  <Step title="Sign in (optional)">
    Create a free account with Google, GitHub, or email and password to sync your settings, bookmarks, installed apps, and progress across sessions.
  </Step>
  <Step title="Start exploring">
    Jump into the games library, open the AI assistant, browse through a proxy, or install apps in the desktop — the platform is yours.
