Crafted Gamz hosts more than one hundred browser games spanning a wide range of genres, all playable directly inside the platform without any downloads, plugins, or extensions. Whether you are looking for a quick puzzle session or an extended action game run, the library is built to be immediately accessible regardless of which mode you are using. Games are a core part of what Crafted Gamz offers, and the platform is organized so that reaching them takes as few steps as possible from any starting point.

## Game Categories

The library covers the genres you would expect from a full-featured browser gaming platform, as well as several that go beyond the traditional unblocked game directory model.

<Accordion title="Action">
  Fast-paced games focused on reflexes and real-time challenges. This is typically the largest and most visited category on the platform.
</Accordion>

<Accordion title="Adventure">
  Exploration-driven and story-light games where progression and discovery are the core loop.
</Accordion>

<Accordion title="Puzzle">
  Logic, pattern recognition, and problem-solving games ranging from classic formats to more inventive designs.
</Accordion>

<Accordion title="Strategy">
  Planning-focused games including tower defense, idle, and resource management titles.
</Accordion>

<Accordion title="Arcade and Classics">
  Retro-style and arcade-format games that prioritize simplicity and replayability.
</Accordion>

<Accordion title="Multiplayer and IO">
  Browser-native multiplayer titles and .io-style games accessible directly through the proxy and game library.
</Accordion>

No installations are required for any category. Every game runs inside the browser using standard web technologies.

## Accessing Games

How you reach the games library depends on which mode you are using. All three modes provide access to the full library, but each surfaces it differently.

<Tabs>
  <Tab title="Website Mode">
    The main landing page in Website mode includes a dedicated games section. From there you can browse the full catalog, filter by category or genre, and launch any game directly. The Website mode game section also surfaces top-game tracking data, so you can quickly identify what is currently popular on the platform.
  </Tab>
  <Tab title="Browser Mode">
    Browser mode exposes the games library through the internal `cg://games` page. Navigate to it from the address bar just as you would any other page. The `cg://games` page presents the full catalog in a browser-native view that fits naturally within the Browser mode interface, including tab support so you can keep a game open alongside other browsing.
  </Tab>
  <Tab title="Desktop Mode">
    In Desktop mode, games are accessible as installable apps from the Desktop App Store. Once installed, a game appears in your dock and launcher for direct access. You can run game apps inside the Desktop window system, which means they open alongside other apps and support minimize, restore, and fullscreen controls.
  </Tab>
</Tabs>

## Top Games Tracking

Website mode includes platform-level statistics and top-game tracking, giving you a real-time view of which games are being played most across the platform. This feature surfaces on the Website mode landing page and game section, and it updates based on actual platform activity rather than a static editorial list. If you are not sure what to play, the top-games feed is a useful starting point — it reflects what the broader Crafted Gamz community is actively running.

## Installing Games (Desktop)

In Desktop mode, games are treated as first-class installable apps rather than simple links. You can browse game apps through the Desktop App Store, install them with a single action, and then access them from the dock or launcher any time you return to Desktop mode. Installed game apps persist across sessions when you are signed in, so your setup carries over without needing to reinstall anything.

Managing game apps works the same way as any other Desktop app — you can pin them to the dock, unpin them, and uninstall them from the App Store or through the AI assistant.

<Tip>
  In Desktop mode, use the launcher to jump into a game without navigating to the App Store. If the game is already installed, typing its name in the launcher opens it immediately in a new Desktop window.
</Tip>

<Note>
  All games on Crafted Gamz run entirely in-browser. No plugins, browser extensions, native executables, or additional software of any kind are required. If your browser supports modern web standards, the games will run.
</Note>
