Crafted Gamz includes built-in media features covering both music and movies, integrated into the platform alongside games, proxy browsing, and the AI assistant. Rather than directing you to an external service, the platform surfaces media content from within its own interface — accessible from the Website mode landing page, from dedicated internal pages in Browser mode, and as installable apps in Desktop mode. Media is treated as a first-class part of the platform experience, not an afterthought, and each mode provides a path to reach it that fits naturally within that environment.

## Music

The music feature gives you access to a streaming music experience without leaving Crafted Gamz. It is available across all three modes, with each providing a slightly different access path suited to the mode's overall design.

<Tabs>
  <Tab title="Website Mode">
    Website mode includes a dedicated music page accessible from the main landing experience. Navigate to it from the home page to open the music interface directly within the platform's website view. This is the most immediate path to music if you are starting from the Website mode landing page and want to listen while browsing other sections.
  </Tab>
  <Tab title="Browser Mode">
    In Browser mode, the music player is available at `cg://music`. Type that address into the Browser mode address bar to load the music interface as a browser tab. Because Browser mode supports full tab management, you can keep `cg://music` open in a background tab while navigating other sites or using the proxy — the music continues playing as you work.
  </Tab>
  <Tab title="Desktop Mode">
    In Desktop mode, music is available as an installable app through the Desktop App Store. Once installed, the music app appears in your dock and launcher, and opens as a Desktop window alongside any other apps you have running. You can minimize it to the dock while it plays, keeping your workspace clean without stopping playback.
  </Tab>
</Tabs>

## Movies

The movies feature provides access to a video streaming experience from within Crafted Gamz. Like music, it is available in all three modes and fits naturally into each mode's navigation structure.

<Tabs>
  <Tab title="Website Mode">
    Website mode includes a dedicated movie page reachable from the main landing experience. Navigate to it from the home page to browse and watch movies directly within the platform's website interface, without switching to a different environment.
  </Tab>
  <Tab title="Browser Mode">
    In Browser mode, movies are accessible at `cg://movies`. Enter that address in the Browser mode address bar to load the movie interface as a full browser tab. The tab-based layout makes it easy to keep a movie running in one tab while you use another tab for browsing or games.
  </Tab>
  <Tab title="Desktop Mode">
    In Desktop mode, movies are available as an installable app from the Desktop App Store. Once installed, the movies app opens as a resizable Desktop window. You can run it fullscreen or alongside other app windows depending on how you prefer to arrange your Desktop workspace.
  </Tab>
</Tabs>

## Accessing Media by Mode

The table below summarizes where to find each media type in each mode.

| Mode | Music | Movies |
|---|---|---|
| Website | Music page from the landing experience | Movie page from the landing experience |
| Browser | `cg://music` internal page | `cg://movies` internal page |
| Desktop | Install from App Store, access via dock or launcher | Install from App Store, access via dock or launcher |

All paths lead to the same underlying content. The mode you choose determines how the media interface is presented and how it integrates with the rest of your session.

<Tip>
  In Desktop mode, install both the music and movies apps and pin them to your dock. That way, media is always one click away regardless of what else you have open in your Desktop workspace — no need to navigate through the App Store or launcher each time you want to switch to a song or film.
</Tip>
