Website mode is the most immediately accessible environment in Crafted Gamz. It presents the platform as a polished, traditional game and proxy site — the kind of layout that feels intuitive the moment you land on it — while quietly offering far more depth than that label usually suggests. It is the right choice for anyone who wants to get started quickly, explore the full feature set without learning a new interface, or simply return to a familiar home base between longer sessions in Desktop or Browser mode.

<Note>
  If you are new to Crafted Gamz, Website mode is the fastest way to get started. You do not need an account to access the game library, AI chat, or proxy tools — everything on the landing page is immediately usable, and signing in later unlocks continuity features like saved preferences and onboarding progress.
</Note>

## What's Included

Website mode brings together every major feature area of Crafted Gamz under a single, navigable landing experience. From here you can reach:

<Accordion title="Main Landing Experience">
  The home page serves as a central hub. It surfaces featured content, quick links to each major section, and platform statistics at a glance. The layout is designed to feel fast and familiar — close to a classic games portal, but extended with modern account and platform features.
</Accordion>

<Accordion title="Game Library">
  Website mode includes a large browser game library spanning dozens of genres. Games open directly in the browser without additional setup. The platform also tracks top games by popularity, so you can quickly find what is trending without browsing the full catalog.
</Accordion>

<Accordion title="App Shortcuts and Wrappers">
  Beyond games, the platform surfaces a curated set of app shortcuts and wrappers — quick-launch tiles for tools and experiences that extend beyond the traditional game-site model.
</Accordion>

<Accordion title="AI Chat">
  An integrated AI chat assistant is available directly from Website mode. It operates independently of Desktop mode's system-aware Jarvis assistant — here it functions as a conversational tool you can open and use alongside games, browsing, or any other activity.
</Accordion>

<Accordion title="Music and Movies">
  Dedicated music and movie pages are accessible from the main navigation. These are not external embeds — they are full sections of the platform with their own layouts and content flows.
</Accordion>

<Accordion title="Virtual Machine Pages">
  Website mode includes access to virtual machine pages — a feature that sets Crafted Gamz apart from most unblocked game sites and reflects the platform's broader ambition as a multi-tool environment.
</Accordion>

<Accordion title="Search and Proxy Section">
  A dedicated search and proxy section lets you access the wider web through Crafted Gamz's proxy infrastructure — powered by Ultraviolet, Scramjet, and Wisp-backed connections — without leaving the Website mode environment.
</Accordion>

<Accordion title="Platform Statistics and Top-Game Tracking">
  Website mode surfaces live platform statistics and a ranked view of the most-played games. These elements reinforce the sense of an active, community-driven platform rather than a static catalog.
</Accordion>

## Getting Around

Navigating Website mode is straightforward. The main landing page organizes content into clear sections, and most areas are reachable within one or two clicks from home.

<Steps>
  <Step title="Start at the landing page">
    The home page is your central reference point. Featured content, section links, and platform stats are all visible here — orient yourself before diving deeper.
  </Step>
  <Step title="Use the main navigation">
    The top-level navigation links out to the game library, apps, AI chat, music, movies, virtual machines, and the proxy search section. Each link loads its destination directly in the same environment.
  </Step>
  <Step title="Browse the game library">
    The game library is searchable and browsable by category. Click any game to open it in its dedicated page — no redirects or external launchers required.
  </Step>
  <Step title="Use search or proxy tools">
    Head to the search and proxy section to reach the wider web. Enter a URL or search query and the platform routes it through the appropriate proxy engine.
  </Step>
  <Step title="Sign in to unlock continuity">
    While guest access works immediately, signing in with Google, GitHub, or email unlocks account-backed features like saved settings, onboarding state, and preferences that persist across visits.
  </Step>
</Steps>

## How It Extends Beyond a Game Site

What separates Website mode from a traditional unblocked-games site is the range of features layered on top of the familiar game-portal foundation.

**Accounts and persistence.** Crafted Gamz includes full account support — Google, GitHub, and email — so your settings and progress are not lost when you close the tab. This is unusual for a site in this category and reflects the platform's commitment to long-term usability.

**AI chat built in.** Rather than pointing users to an external AI tool, Website mode includes an integrated AI chat assistant. It lives alongside the rest of the platform and is accessible without opening a new tab or leaving the Crafted Gamz environment.

**Media without leaving the platform.** Music and movie sections keep entertainment within the same experience. You do not need to switch to a streaming site or open a separate app.

**Proxy access as a first-class feature.** Most game sites treat proxy tools as an afterthought. In Crafted Gamz, the search and proxy section is a core part of the Website mode layout — backed by multiple proxy engines and designed to handle real browsing, not just a handful of whitelisted sites.
