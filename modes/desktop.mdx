Desktop mode is the most expansive environment in Crafted Gamz. Where Website mode offers a familiar landing page and Browser mode delivers a full proxy browsing session, Desktop mode goes further — presenting the platform as a lightweight, browser-native operating system with a presentation that strongly echoes macOS. You get draggable windows, a persistent dock, a searchable app launcher, an installable app ecosystem, and a built-in AI assistant that does not just answer questions but actively controls the environment around you. For users who want Crafted Gamz to feel like their own workspace rather than a site they visit, Desktop mode is where that experience lives.

## Environment Components

Desktop mode is made up of several interconnected components that together create the sense of a real operating system running inside a browser tab.

<Accordion title="Desktop Layout and Windows">
  The base layer of Desktop mode is a windowed canvas. Apps open as floating windows that can be moved, resized, minimized, maximized to fullscreen, and restored — all within the browser. Multiple windows can be open simultaneously, which means you can run a game alongside the app store, or keep the AI assistant visible while exploring other content. The desktop surface itself is persistent: your layout and open windows are part of your session state.
</Accordion>

<Accordion title="Dock">
  The dock sits at the bottom of the screen and serves two purposes simultaneously. It shows your pinned apps — items you have chosen to keep accessible at all times — and it also reflects currently running apps as they are opened. A pinned app that is also running shows both states at once. Pinning and unpinning can be done manually or through the AI assistant.
</Accordion>

<Accordion title="Launcher">
  The launcher gives you fast access to your installed apps without navigating through the app store. It is the Desktop mode equivalent of an application menu — open it, search or browse, and launch what you need.
</Accordion>

<Accordion title="App Store">
  The app store is where you discover and install new content. Crafted Gamz categorizes installable apps into three types: game apps, internet apps, and utility apps. Browsing the store, installing an app, and opening it all happen within the desktop environment without any page reload or navigation away from your current session.
</Accordion>

<Accordion title="Installable App Types">
  Desktop mode supports three categories of installable apps:

  - **Game apps** — browser games that install into the desktop and open as windows, integrating the Crafted Gamz game library directly into the OS-style interface.
  - **Internet apps** — proxy-powered web destinations that open as windowed browsing sessions, bringing proxy access into the desktop context.
  - **Utility apps** — tools and platform features (including the AI assistant, settings, and other utilities) packaged as installable desktop apps.
</Accordion>

## Top-Bar Widgets

A persistent top bar runs across the top of the Desktop mode canvas, providing at-a-glance system information without interrupting your workflow. The top bar surfaces:

- **Account status** — your current sign-in state and identity, mirroring the account system shared across all three modes.
- **Platform statistics** — live data about the Crafted Gamz platform, surfaced directly in the desktop environment so you do not need to navigate away.
- **Network state** — connection status information relevant to proxy and browsing functionality.
- **Weather** — a lightweight weather widget that contributes to the OS-style ambient feel of the environment.

## Window Management

Desktop mode's window management system gives you meaningful control over how content is arranged on your canvas. Every open app window supports the following behaviors:

<Steps>
  <Step title="Fullscreen">
    Expand any window to fill the entire desktop canvas. Useful for games, media, or any app you want to focus on without distraction.
  </Step>
  <Step title="Minimize">
    Collapse a window out of the canvas while keeping the app running. Minimized apps remain visible in the dock so you can restore them at any time.
  </Step>
  <Step title="Restore">
    Bring a minimized or repositioned window back to its previous size and position. Useful after switching between tasks or returning to a window you set aside.
  </Step>
  <Step title="Multi-window">
    Keep several app windows open on the canvas simultaneously. There is no artificial limit on how many windows you can have open at once — manage your workspace the way that suits how you work.
  </Step>
</Steps>

## The AI Assistant

Desktop mode's AI assistant is one of its most distinctive features. Unlike the conversational AI chat available in Website mode, the Desktop mode assistant is system-aware — it has access to the state of the environment around it and can take direct action within it. The experience is closer to a lightweight Jarvis-style helper than a standard chatbot.

In addition to conversation, the assistant can interact with the desktop itself and perform a range of real actions:

| Action | What the assistant does |
|---|---|
| List installed apps | Returns a list of apps you currently have installed in your desktop |
| Retrieve store apps | Fetches available apps from the app store on request |
| Install apps | Installs an app from the store without you needing to open the store manually |
| Open apps | Launches any installed app as a window on the desktop canvas |
| Close windows | Closes a specific open app window |
| Minimize windows | Minimizes a window to the dock |
| Pin apps | Adds an app to the dock for persistent access |
| Unpin apps | Removes an app from the dock |
| Open settings | Navigates to the desktop settings panel |
| Open app store | Opens the app store window directly |

<Tip>
  The AI assistant is one of the most efficient ways to navigate Desktop mode without touching the mouse. You can say "install [app name]", "open the app store", "minimize all windows", or "pin [app name] to the dock" and the assistant will handle it immediately. For users on Chromebooks or other keyboard-first setups, this makes the entire environment hands-free navigable.
</Tip>
