Crafted Gamz is not a single-purpose site. Rather than forcing every feature into one flat interface, the platform is organized around three distinct modes — Website, Desktop, and Browser — each shaped to match a different style of use. Whether you want to jump into a game within seconds, settle into a persistent workspace with a dock and windows, or browse the web through a proxy with full tab management, there is a mode built for that intent. Understanding the difference between them helps you get the most out of the platform from the moment you arrive.

## Quick Comparison

The table below summarizes what each mode brings to the table. All three modes share the same underlying account system, so your preferences, bookmarks, and state follow you no matter which environment you are using.

| Feature | Website | Desktop | Browser |
|---|---|---|---|
| Game library | ✅ | ✅ (via app store) | ✅ (via `cg://games`) |
| AI chat | ✅ | ✅ (system-aware AI) | ✅ (via `cg://ai`) |
| Proxy browsing | ✅ (search/proxy section) | ✅ (via internet apps) | ✅ (full browser environment) |
| Media (music & movies) | ✅ | ✅ (via apps) | ✅ (via `cg://movies`, `cg://music`) |
| Virtual machines | ✅ | ✅ (via apps) | ✅ (via `cg://vms`) |
| App store | ❌ | ✅ | ❌ |
| Windowed multitasking | ❌ | ✅ | ❌ |
| Tab management | ❌ | ❌ | ✅ |
| Bookmarks bar | ❌ | ❌ | ✅ |
| Theme & background presets | ❌ | ❌ | ✅ |
| Top-bar system widgets | ❌ | ✅ | ❌ |
| Account continuity | ✅ | ✅ | ✅ |

## Which Mode Should You Start With?

Different goals call for different starting points. Here is a simple guide to help you decide.

<Tabs>
  <Tab title="Quick games or tools">
    If you want to jump straight into a game, find a proxy link, or use the AI assistant without any setup, **Website mode** is your best starting point. It loads immediately and presents everything on a familiar landing page — no configuration required. You can always switch to another mode later.
  </Tab>
  <Tab title="A persistent workspace">
    If you want Crafted Gamz to feel like your own environment — with a dock, installable apps, resizable windows, and an AI assistant that knows what is running — start with **Desktop mode**. It is the most expansive environment on the platform and rewards continued use as you build out your app setup.
  </Tab>
  <Tab title="Proxy browsing as a daily driver">
    If your primary goal is to browse the wider web through a proxy, manage multiple tabs, save bookmarks, and work with a real navigation history, start with **Browser mode**. It is designed to make proxy access feel like a proper browsing session rather than a temporary utility.
  </Tab>
</Tabs>

<Tip>
  You are never locked into a single mode. Crafted Gamz makes it easy to switch between Website, Desktop, and Browser at any time. Because your account state is shared across all three, your bookmarks, preferences, and onboarding progress carry over automatically — so switching is always a low-friction experiment, not a commitment.
</Tip>
